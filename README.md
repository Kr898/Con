# Conversation — Page 27
موقع تعليمي ثابت لدرس Section 8: Conversation بين Michael وMr. Parker، مستخرج من الصورة المرفقة IMG_1043.jpeg. عنوان «On the plane» عنوان تنظيمي مستوحى من نشاط Your Turn، وليس اسم وحدة من الكتاب.

## محتويات الحزمة
- index.html: صفحة الموقع.
- styles.css: التصميم المتجاوب، وإعداد تقليل الحركة.
- lesson.js: نص الدرس والترجمة والأسئلة وبيانات التقدم.
- app.js: التفاعلات والحفظ المحلي.
- .nojekyll: ملف للنشر الثابت.
- QA.md: نطاق الفحص وحدوده.

## رفع الموقع إلى GitHub Pages
1. فك الضغط وارفع محتويات الحزمة إلى جذر مستودع GitHub؛ يجب أن يظهر index.html مباشرةً في الجذر.
2. افتح Settings → Pages.
3. في Build and deployment اختر Deploy from a branch.
4. اختر فرع main ومجلد /(root)، ثم Save.
5. بعد اكتمال النشر، افتح الرابط المعروض في Pages.

المسارات المحلية نسبية، لتناسب نشر الموقع داخل مستودع. لا توجد حزم npm أو خطوة بناء أو خادم خلفي أو تسجيل دخول.

## استخدام الموقع
- English هي اللغة الأساسية، وArabic Help / Hide Arabic يُظهر أو يخفي الشرح العربي.
- اضغط عبارات الحوار الملونة للانتقال إلى شرحها في Real Talk.
- أسئلة الفهم أربعة لكل شخصية (ثمانية إجمالًا). اختيار الإجابة يكشف التصحيح والدليل من الحوار ويُحدّث عدّاد النتيجة.
- Try Again يمسح محاولات أسئلة الفهم فقط.
- Switch Roles يبدّل أدوار الطالبين. افتح تلميحات Your Turn لرؤية نماذج للمحادثة، ثم أجب شفهيًا.
- التقدم وتفضيل العربية والأدوار تحفظ في LocalStorage. عند منع الحفظ، تظهر رسالة ويبقى النشاط متاحًا أثناء الزيارة.
- يحترم الموقع prefers-reduced-motion. كل الأنشطة تعمل باختيار أو نقر أو إجابة شفهية، دون إجبار الطالب على الكتابة.
- لا يتضمن الموقع صوتًا أو مشغّل فيديو أو أي استدعاء لشبكة خارجية. لا يرسل إجابات الطالب.

## دقة المحتوى
- الحوار الإنجليزي مراجع بصريًا مقابل الصورة: عشر مداخلات، وثلاث عبارات Real Talk، وأربعة أسئلة أصلية لكل شخصية، وثلاثة تلميحات Your Turn.
- نص الحوار بقي كما في الصورة. الترجمة العربية مساعدة.
- خيارات الاختبار والصياغة المساعدة تعليمية، وليست نقلًا حرفيًا من الكتاب. الأمثلة الجديدة تحت «توضيح إضافي».
- عودة Mr. Parker موصوفة بـ probably next week، وليست «أسبوعًا بالضبط».
- الرياض كمدينة إقامة Mr. Parker استنتاج من ذكر فرع الشركة، وليست تصريحًا مباشرًا بالإقامة في الحوار؛ وُسمت بوضوح داخل السؤال والتصحيح.

يمكن معاينة الملفات محليًا بفتح index.html. إن قيد المتصفح الحفظ عند فتح ملف محلي، استخدم النسخة المنشورة على GitHub Pages أو خادمًا محليًا ثابتًا.
